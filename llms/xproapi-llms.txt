## API endpoints

- [X (Twitter) User API — Get a Profile by Username](https://xproapi.com/docs/user-info/): Get an X (Twitter) user’s profile as JSON by username: numeric user ID, name, bio, follower and following counts, verified and protected status.
- [Batch X (Twitter) User Lookup API — Many Profiles in One Call](https://xproapi.com/docs/batch-user-info-usernames/): Look up many X (Twitter) profiles in one API call by username. Returns the same user object as a single lookup; missing or suspended accounts are left out.
- [X (Twitter) “About This Account” API — Country, Created Date, Username Changes](https://xproapi.com/docs/user-about/): Read the “About this account” details of an X (Twitter) user as JSON: account creation date, the country it is based in, sign-up source and username changes.
- [X (Twitter) User Search API — Find Accounts by Keyword](https://xproapi.com/docs/user-search/): Search X (Twitter) accounts by keyword through an API. Returns matching profiles in the order X’s people search ranks them, with cursor pagination.
- [X (Twitter) Followers API — Get a User’s Follower List](https://xproapi.com/docs/followers/): Get the followers of any public X (Twitter) account as JSON, most recent first, with cursor pagination and up to 200 users per page.
- [X (Twitter) Following API — Get the Accounts a User Follows](https://xproapi.com/docs/followings/): Get the list of accounts any public X (Twitter) user follows as JSON, most recent first, with cursor pagination. Poll the first page to detect new follows.
- [X (Twitter) User Tweets API — Get a User’s Latest Tweets](https://xproapi.com/docs/last-tweets/): Get the latest tweets and retweets of an X (Twitter) user as JSON by username or user ID, newest first, with optional replies and cursor pagination.
- [X (Twitter) User Timeline API — Tweets, Replies and Parent Tweets](https://xproapi.com/docs/tweet-timeline/): Read an X (Twitter) user’s timeline as JSON: tweets, optional replies, and optionally the tweet each reply answers, with cursor pagination.
- [X (Twitter) Tweet Lookup API — Get Tweets by ID](https://xproapi.com/docs/tweets-by-ids/): Fetch tweets by ID through an API: many tweets in one call, as JSON with text, engagement counts, author and media. Deleted tweets are left out.
- [X (Twitter) Search API — Search Tweets With Operators](https://xproapi.com/docs/advanced-search/): Search tweets through an API with X’s full operator syntax: keywords, hashtags, from:, since:, min_faves: and more. Latest or Top results as JSON.
- [X (Twitter) Mentions API — Get Tweets Mentioning a User](https://xproapi.com/docs/mentions/): Get tweets that mention an X (Twitter) user as JSON, newest first, with optional time range and cursor pagination.
- [X (Twitter) Tweet Replies API — Get Replies to a Tweet](https://xproapi.com/docs/replies/): Get the replies to a tweet as JSON, newest first, with optional time range and cursor pagination.
- [X (Twitter) Tweet Replies API v2 — Replies Ranked by Relevance, Latest or Likes](https://xproapi.com/docs/replies-v2/): Get the replies to a tweet as JSON in the order X shows them: by relevance, latest or most liked, with cursor pagination.
- [X (Twitter) Quote Tweets API — Get Tweets Quoting a Tweet](https://xproapi.com/docs/quotes/): Get the quote tweets of a tweet as JSON, newest first, with optional time range and cursor pagination.
- [X (Twitter) Retweeters API — Get Accounts That Retweeted a Tweet](https://xproapi.com/docs/retweeters/): Get the accounts that retweeted a tweet as JSON, each with profile details, follower counts and verification, with cursor pagination.
- [X (Twitter) Thread API — Get a Tweet’s Full Conversation](https://xproapi.com/docs/thread-context/): Get the conversation around a tweet as JSON in reading order: the tweets it replies to, the tweet itself, then its replies.
- [X (Twitter) Article API — Get a Long-Form Article as JSON](https://xproapi.com/docs/article/): Get an X (Twitter) article as structured JSON by the ID of the tweet that shares it: title, cover image, author, counts and content blocks.
